Entry for the make.fun bounty [The Robot Vacuum's Funniest Excuse](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2).

`main.py` (Python 3, standard library only) writes one line of at most 120
characters to `/output/entry.txt`: the excuse a robot vacuum gives for
missing a spot.

Run it with:

```sh
python3 main.py
```
